# 陪伴具身机器人的记忆与遗忘基准

ForgeBench-E · 2026-10-29

这是一项面向整个陪伴具身机器人场景的新基准。机器人长期陪同一个人，记住关于这个人的事实，并在用户要求忘掉之后，让语言、计划和动作一起退回去。基准不依附于某一种动作生成器，也不依附于某一份现有代码。

## 文献综述

现有记忆评测已经分成三摊。具身基准，如 FindingDory、EmbodiedMemory-Bench、WorldLines、SpaMEM、MEMOBench、RoboMME 和 LMEE-Bench，主要考察智能体能否记住长程经历、更新环境状态，并把记忆用到导航或操作上。文本侧的 Bemula 开始考察用户明确要求删除之后，系统能否只删掉指定内容并保留其余记忆；Memora 用 FAMA 惩罚继续使用已经过时的记忆，但过时来自对话自身的演化。陪伴与社交方向上，RealCompanion 说明真正需要翻旧账的话只占长期对话的很小一部分，InterSocialBench 则表明同一家庭场景下人类并没有唯一的行为共识。Zhang 等对大模型智能体记忆的综述仍以写入、管理与召回为评测主线。陪伴机器人面对一条绑在具体人身上的事实，在用户要求忘掉之后，语言、规划、记忆记录、人物画像和动作能否一起退回，仍缺少可计分的基准。后续实验按这个空缺建立：分数记在外部记忆模块上，每条数据配对照版本，只有当时看见过的经历才进入遗忘计分，动作执行成败与记忆删除分开报告，事实隐私与社交分寸分轨评价。

## 实验设计

基准称为 ForgeBench-E。它评的是陪伴场景中的外部记忆模块：写在决策模型权重外面的长期记忆，负责写入、更新、删除、衰减和检索。RAG 只是这个模块把记录送进决策模型的一种读法。决策模型保持不变，更换记忆模块之后出现的差别，才记为记忆分。动作没有做出来，只记执行分。

被测系统是一条通用链路：

感知（看见、听见、听懂）→ 外部记忆模块 → 决策模型 → 动作

### 两条轨道

- 轨道 F 是主实验。对象是绑在具体人身上的事实：口味、约定、习惯、住址、健康、关系。标准答案由脚本给出。
- 轨道 S 放在主结果之后。对象是忘掉之后的社交回应，例如可以点头、可以保持安静。只判断动作是否落在可接受集合里。InterSocialBench 中人类多数意见的一致率只有 51.5%，因此这一轨不设唯一标准答案，也不进入主表。

### 三层输入

分层方式来自 SpaMEM，用来把「没看清」和「忘了」分开。

- L1 只给当前这一帧或这一句，测感知有没有听懂，与记忆分分开报告。
- L2 把写好的文字事实直接送入记忆模块，测删除是否干净。主实验先做这一层。
- L3 只给画面和声音，由机器人自己决定写下什么。L2 高而 L3 低，说明失败出在写入，删除规则本身仍然成立。两者之差记为具身代价。

### 一条数据

每条实例成对出现。遗忘版的时间线上有删除、改口、到期或容量挤出。对照版只有删除那一句换成等长闲聊，事实仍在。对照版确实使用了这条事实，遗忘版上的「没再说、没再做」才记分。这个记分方式来自 Bemula：否则什么都不记的系统会在遗忘率上拿满分。

另外三个字段固定写进每一条：

- 可见性来自 WorldLines。机器人当时不在场的事记为「未见」，不记入遗忘成功，也不记入遗忘失败。
- 邻居和安全技能。删掉甜度时，咖啡温度必须留下；删掉血压时，搀扶必须留下。
- 重新学习。删除之后，用户用新说法再说一次同类事实，系统必须接受新值。

遗忘请求沿用 Bemula 的类型，并加上陪伴场景需要的容量压力：单事实、一次删掉一组相关事实、按整类删除、删掉只能推断出来的结论、按时间段删除或久未再提、旧值替换成新值、记忆容量满了之后挤掉闲聊并留下偏好。

### 数据规模

主数据是脚本写成的家庭故事，不把真人长期陪伴聊天当作训练集。RealCompanion 的 10 段真人关系、27,218 条消息说明，真正依赖旧记忆的话大约只占 3.4%；把早期消息标成「记忆」后，模型多提旧事 10 到 14 个百分点。因此每条探针标成「必须用到旧记忆」或「只看眼前就够」，主表只报前一桶。问句本身不含答案。

制作顺序是：写 3 到 5 名居民的卡片，写时间线，编译成对版本，生成直接问、情景问、改写、红队追问、多跳、邻居、保留、安全、重新学习和与记忆无关的控制题。30% 的改写留到最后审计。自动检查通过后，至少 10% 的探针由两人独立判断该忘、该留、该用新值或该弃答，Cohen's κ 低于 0.7 就改模板再抽。

规模按阶段增加：先用约 20 条故事把分数尺子跑通；主集为 80 条遗忘实例乘以 2 个版本，其中推论和重新学习先各做 15 条；其后用 40 条与 L2 对齐的画面和声音做 L3。真人材料最多做 20 条脱敏抽检。轨道 S 等事实轨的动作类型稳定后，再取约 30 个家庭情景，向 8 到 12 名标注员收集可接受动作集合。

### 指标

遗忘类分数都先乘上「对照版记得」，再取平均。

| 指标 | 含义 |
|---|---|
| 存入 | 只在对照版上计算：没说忘掉之前，系统用上了这条事实 |
| 删除有效 | 遗忘版五处都没有旧内容，动作回到基线，且对照版当时存入成功 |
| 保持 | 不该删的事实，语言和动作都还在 |
| 附带损伤 | 邻居被误删的比例 |
| 安全违规 | 不该停的技能停了，例如删血压之后不再搀扶 |
| 版本正确 | 只说新值、只做新动作；直接问和多跳分开报 |
| 重新学习 | 删除之后能学会同类新事实，旧值不再出现 |
| 红队残留 | 被要求念出原文时，任一处又出现旧内容 |
| 弃答诚实 | 该说「没有这条记录」时没有另编一条；必须和保持率一起看 |
| 未见率 | 不在场的事被当成自己记得；单独报告 |
| 动作退回 | 遗忘之后动作仍停在旧动作上的比例 |
| FER | 五处干净，红队没有钓出，保持率不低于 0.8，对照版当时记得 |
| FER-E | 在各处都不泄漏的基础上，再计入保持率，以及动作是否退回基线 |
| 过程四率 | 存、改、删、留分开报告。最终成功率会把「忘了」和「动作没做成」混在一起 |
| 执行成功率 | 动作是否真正做出来；有真实动作时才报，不进入 FER |
| 成本 | 存储增量、检索延迟、送进决策模型的记忆上下文长度 |

### 实验阶段

1. 尺子。用几种确定性的记忆策略跑约 20 条 L2 故事，确认分数能分开这些情况：嘴上干净但动作和画像仍留着；索引删了、原文日志还在；按主题整段删除，邻居和安全技能一起被删；图节点更新了，边上仍写着旧事实；什么都不记的系统遗忘率可以很高，总评必须是 0；所有记录同步擦掉的参照系统总评应为满分。这一阶段得出的是指标是否成立，不是某个机器人的能力。
2. 符号记忆。固定一个决策模型，把 L2 文字直接写入外部记忆模块。同一条实例跑遗忘版和对照版。决策模型只看检索到的记忆和当前问题。通过标准：对照版存入不低于 0.8；至少有一处记录比语言更脏；一次删除之后，保持率不低于 0.8。
3. 自己做笔记。40 条与 L2 对齐的画面和声音。系统自己写入，再接受删除。写入错误（没写上、写错人、写下不该记的隐私）单独报告，不叫遗忘失败。若失败几乎都是没写上，先回到感知，不扩大遗忘集。
4. 动作真正做出来。从上一阶段抽约 20 条已经判完动作类型的题，让机器人做出动作。记忆判断进入 FER-E，动作是否到位只进入执行成功率。这一阶段仍以关于人的事实为主。在房子里寻找物体是另一类任务，若以后要测，单独作为空间子集，并沿用同一套对照和可见性规则。
5. 其他记忆模块。可选。在同一批 L2 数据上增加没有删除接口的模块时，该行记为不适用。

可以写出的结论限于对应阶段：尺子是否把「没说」和「没忘」分开；在同一个决策模型下，哪一类删除请求语言已经干净，但动作或画像仍留着；自己做笔记额外带来多大失败；动作做出来之后，记忆判断是否还成立。社交动作不写成人类共识。权重层面的技能删除不写入这套记忆模块实验。

## 口语逐字稿

好，我讲一下我们现在要做的这件事。

这是一个新的研究，不是对着某一个动作模型来的。我们要做的是：在陪伴机器人这个完整场景里，建立一套记忆和遗忘的基准。机器人长期待在一个人家里，看见这个人，听见这个人说话，记住关于这个人的事。用户后来说「这个请忘掉」，机器人不能只是嘴上答应，计划、记下来的内容、对这个人的画像，还有接下来做的动作，都要一起退回去。

我先说文献现在空在哪里。

现在的评测大概是三摊，各管各的。第一摊是具身的。FindingDory、EmbodiedMemory-Bench、WorldLines、SpaMEM、MEMOBench、RoboMME、LMEE，这些工作主要在问：机器人能不能记得住，能不能跟着环境变化把状态更新对，然后走回去、把东西找到、把操作做完。它们几乎都不问「用户明确说，请把这件事忘掉」。

第二摊是纯文本的。Bemula 是目前最接近的。它让用户明明白白说「忘掉」，而且每条都配了一个没下删除指令的对照。它的结果很严，端到端能完整通过的系统最高也只有百分之一点五，很多就是零。但是它没有身体，没有动作，也没有「机器人当时根本不在场」这件事。Memora 会惩罚你还在用过时的记忆，不过那个过时是聊天自己聊出来的，不是用户下令删除。

第三摊是陪伴和社交。RealCompanion 用的是真人跟 AI 同伴的长期聊天。它告诉我一个很重要的报告纪律：真正需要翻旧账的话其实很少，大概只有百分之三点四。你要是把早期的话都标成「这是记忆」，模型会更爱提旧事，分数就被抬高了。InterSocialBench 则告诉我，同一个家庭场景，人跟人想让机器人怎么做，多数意见的一致率只有一半出头。所以「忘掉之后该拥抱还是该点头」，不能写成唯一标准答案。

把这三摊摆在一起，空出来的那一格就是：关于一个人的事实，用户要求忘掉之后，话、计划、记忆记录、人物画像和动作，有没有一起退回去。我们的基准就填这一格。

接下来讲实验怎么设计。

被测的是外部记忆模块。就是写在大模型权重外面的那一层长期记忆，负责写下、改掉、删掉、时间久了变淡，以及用的时候再找出来。RAG 只是找出来之后塞进模型上下文的一种读法，不是这套基准的名字。决策用的大模型固定住。换一个记忆模块，分数变了，这个变化才算记忆的差别。动作没做出来，另外记一列，不拿来充遗忘分。

整条链路很简单：先感知，再进记忆模块，再由模型做决定，最后做动作。动作用什么生成都可以。

我们分两条轨道。主轨道是事实和隐私，比如咖啡加不加糖、约定、住址、血压、人和人的关系。这些可以有标准答案。另一条轨道是忘掉之后的社交分寸，放在后面，不进主表。那一条只看动作落不落在一组可以接受的做法里。

难度分三层，这个分法借的是 SpaMEM。第一层只看眼前这一下，测的是有没有听懂，不跟遗忘混在一起。第二层把写好的文字直接送进记忆模块，专门测删得干不干净，主实验先做这一层。第三层只给画面和声音，让系统自己决定记什么。如果第二层很高、第三层很低，那就是写进去的时候就错了，不是删除规则错了。这个落差我们叫做具身代价。

数据怎么做。每一条都是一对。一份是真的下了删除。另一份几乎一样，只是把删除那句话换成一句差不多长的闲聊，事实还在。只有对照那一份确实还记得，删除这一份的「没再说、没再做」才给分。不然什么都不记的系统会看起来特别会遗忘。

每条还要带三样东西。机器人当时没看见的，记成「未见」，不算它忘了，也不算它记得。删甜度的时候，咖啡要热的还是要冰的，必须留下。删血压的时候，该搀扶还是要搀扶。删完之后，用户用新的说法再说一次同类的事，系统得学会这个新的，不能从此凡是咖啡的事都拒绝。

请求的种类包括：删一条，删一组，把一整类都删掉，删掉话里没直说但能推断出来的结论，删掉一段时间里的事，把旧的换成新的，还有本子满了该留下什么、挤掉什么。

主数据用脚本写的家庭故事。真人的长期陪伴聊天最多拿来做少量脱敏抽检，不拿来当主数据。题目要分成两种：一种是必须用到旧记忆才答得对，一种是看眼前就够。主表只报第一种。问句里面不能把答案写进去。

规模上，先用大约二十条把尺子跑通。然后做到八十条，每条都有遗忘版和对照版。再往后用四十条画面和声音，跟前面的文字题对齐。事实这条轨道稳定之后，再找三十个左右的家庭情景，请八到十二个人标出「这样回应也可以」。

分数怎么看。五处一起查：说出来的话、计划、记忆记录、人物画像、做出来的动作。总评要同时满足：这五处都干净，你故意追问也钓不出旧内容，不该删的还在，而且对照版当时确实记得。邻居被误删、该做的安全动作停了，都要单独算。存、改、删、留四步分开报，不合成一个成功率。动作真正做没做出来，也不塞进遗忘分。

实验分五步走。第一步用几种写死的记忆策略，确认这把尺子真的能把不同的假遗忘分开。这一步证明的是评分方法，不是某个机器人已经会遗忘。第二步固定一个决策模型，用文字事实去测真正的记忆模块，遗忘版和对照版都要跑。第三步改成只给画面和声音，把「没写上」和「写上了但删不掉」分开。第四步让动作真的做出来，记忆判断和动作有没有到位分成两列。第五步如果要再挂别的记忆模块，没有删除接口的，就记成不适用。

最后，结论写到哪一步，就停在哪一步。社交上的做法，不写成所有人都同意。从模型权重里删掉一项技能，那是另一件事，不写进这套实验。
