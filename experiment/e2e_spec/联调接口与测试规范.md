# 端到端联调规范（感知 → 决策 → MoMask → 队友执行）

> 目标：在不改业务代码前，先冻结接口与测试口径。  
> 测试机：树莓派 5 / 4GB；真机：树莓派 5 / 16GB。  
> 执行层：TonyPi ActionGroup（即时） + MoMask 关节 `(T,22,3)`（给队友）。

---

## 1. JSON 接口定义

### 1.1 感知层输出（Perception State）

小模型 / 规则模块产出，**不直接喂给 MoMask**。

```json
{
  "session_id": "s001",
  "timestamp_ms": 1710000000000,
  "user_id": "u001",
  "vision": {
    "face_detected": true,
    "emotion": "sad",
    "emotion_conf": 0.78,
    "gesture": null,
    "notes": "head down, low activity"
  },
  "audio": {
    "transcript": "我今天有点累，陪我一下吧",
    "emotion": "sad",
    "emotion_conf": 0.71,
    "language": "zh"
  },
  "fused": {
    "emotion": "sad",
    "intent": "comfort_request",
    "urgency": "low",
    "confidence": 0.74
  }
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `fused.emotion` | 是 | `neutral/happy/sad/angry/fearful/disgust/surprised` |
| `fused.intent` | 是 | 粗意图：`greeting/comfort_request/play/stop/help/unknown` |
| `fused.confidence` | 是 | 0–1；&lt;0.45 走安全默认动作 |
| `audio.transcript` | 建议 | 可空（纯视觉场景） |
| `vision.emotion` | 建议 | 可空（纯音频场景） |

### 1.2 决策层输出（Decision / Planner）

小 LLM 只吃「感知 JSON + 简短历史」，强制输出下面格式。

```json
{
  "session_id": "s001",
  "emotion": "sad",
  "intent": "comfort_request",
  "action_prompt": "a person gently waves with the right hand, then bows slightly in a caring way",
  "action_group": ["wave", "bow"],
  "response_text": "我在这儿陪你，慢慢来。",
  "motion_length_hint": 0,
  "confidence": 0.81,
  "fallback": false,
  "reason": "user looks tired and asked for company"
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `action_prompt` | 是 | **英文**、HumanML3D/MoMask 风格动作描述 |
| `action_group` | 是 | TonyPi 预设动作名列表；无可匹配时 `[]` |
| `response_text` | 否 | 语音回复文案（中/英） |
| `motion_length_hint` | 否 | `0`=自动估计；或建议帧数（如 80/120/160） |
| `fallback` | 是 | `true` 表示低置信度走默认安全动作 |
| `confidence` | 是 | 决策置信度 |

`action_group` 允许值（与现有 TonyPi 对齐，可扩展）：

`stand, go_forward, back_fast, left_move_fast, right_move_fast, turn_left, turn_right, wave, bow, squat, chest, twist, left_shot_fast, right_shot_fast, sit_ups, wing_chun, stepping`

### 1.3 MoMask / 交付给队友的包（Motion Package）

```json
{
  "session_id": "s001",
  "action_prompt": "a person gently waves with the right hand, then bows slightly in a caring way",
  "emotion": "sad",
  "joints_path": "out/s001_joints.npy",
  "joints_shape": [120, 22, 3],
  "fps": 20,
  "repr": "joint3d_smpl22",
  "units": "meters_approx",
  "coord_frame": "y_up_root_relative",
  "timing": {
    "perception_s": 0.42,
    "decision_s": 0.55,
    "momask_gen_s": 2.21,
    "recover_s": 0.001,
    "total_s": 3.18
  },
  "quality": {
    "valid_ratio": 1.0,
    "mean_speed": 0.012,
    "mean_jerk": 0.004,
    "max_root_disp": 0.35
  }
}
```

队友最小读取约定：

1. 读 `joints.npy`，形状 `(T, 22, 3)`，`float32`
2. 用 `fps` 做时间轴
3. 先做重定向到机器人自由度；在重定向完成前，真机执行走 `action_group`

## 2. 延迟预算（目标交互感）

| 阶段 | 4GB 测试机目标 | 16GB 真机目标 | 备注 |
|---|---:|---:|---|
| 视觉小模型 | ≤ 0.30 s | ≤ 0.20 s | 单帧/少帧，不做全量 VLM |
| 音频 ASR + 语音情绪 | ≤ 0.80 s | ≤ 0.60 s | 短句；可与视觉并行 |
| 决策小 LLM | ≤ 0.80 s | ≤ 0.60 s | 只吃结构化 JSON，禁长上下文 |
| MoMask 生成 | ≤ 2.50 s | ≤ 2.00 s | 已测 4GB ≈ 2.3 s |
| 关节恢复 / 打包 | ≤ 0.05 s | ≤ 0.05 s | 可忽略 |
| **端到端（感知并行）** | **≤ 4.0 s** | **≤ 3.0 s** | 以 max(视,听)+决策+生成 估算 |
| ActionGroup 即时反馈 | ≤ 0.20 s 启动 | ≤ 0.20 s | 与 MoMask 并行，先动起来 |

通过标准（冒烟）：

- JSON 解析成功率 ≥ 90%
- `action_prompt` 非空且为英文动作句 ≥ 90%
- 关节 `valid_ratio = 1.0`
- 端到端 P50 ≤ 预算；P95 ≤ 预算 × 1.3

## 3. 20 条端到端联调样例

说明：先用「伪感知 JSON」驱动，不接真实摄像头/麦克风；验证决策格式 → MoMask → 关节落盘。

| ID | 场景 | fused.emotion | intent | 期望 action_group（示例） | 期望 action_prompt 方向 |
|---|---|---|---|---|---|
| E01 | 见面打招呼 | happy | greeting | `["wave"]` | 挥手致意 |
| E02 | 开心庆祝 | happy | play | `["chest"]` | 双手举起庆祝 |
| E03 | 邀请跳舞 | happy | play | `["twist"]` | 轻快左右摇摆 |
| E04 | 用户说累了 | sad | comfort_request | `["bow"]` 或 `["wave","bow"]` | 轻柔安抚姿态 |
| E05 | 低头沉默 | sad | comfort_request | `["bow"]` | 缓慢点头/鞠躬关心 |
| E06 | 生气抱怨 | angry | help | `["stand"]` | 站定、双手打开安抚，避免攻击动作 |
| E07 | 愤怒跺脚情绪 | angry | unknown | `["stand"]` | 稳定站立，不要模仿攻击 |
| E08 | 突然惊吓 | fearful | help | `["stand"]` | 缓慢举手安抚，不要猛冲 |
| E09 | 害怕后退 | fearful | comfort_request | `["bow"]` | 温和鞠躬并举手示意安全 |
| E10 | 厌恶推开 | disgust | stop | `["stand"]` | 后退半步并摆手拒绝 |
| E11 | 惊讶发现 | surprised | unknown | `["wave"]` | 短促抬手表示惊讶后恢复 |
| E12 | 中性询问天气 | neutral | unknown | `[]` | 可站立微点头；或仅口头回复 |
| E13 | 让机器人前进 | neutral | play | `["go_forward"]` | 向前走几步 |
| E14 | 让机器人后退 | neutral | play | `["back_fast"]` | 向后退 |
| E15 | 左转看看 | neutral | play | `["turn_left"]` | 左转身体 |
| E16 | 挥手再见 | happy | greeting | `["wave"]` | 挥手告别 |
| E17 | 请求下蹲演示 | neutral | play | `["squat"]` | 下蹲再站起 |
| E18 | 低置信度噪声 | unknown | unknown | `["stand"]` | fallback=true，安全站立 |
| E19 | 纯视觉无语音（笑） | happy | greeting | `["wave"]` | transcript 为空仍能决策 |
| E20 | 纯语音无视听帧 | sad | comfort_request | `["bow"]` | vision 缺失仍能决策 |

### 样例输入模板（E04）

```json
{
  "session_id": "E04",
  "timestamp_ms": 1,
  "user_id": "demo",
  "vision": {"face_detected": true, "emotion": "sad", "emotion_conf": 0.8, "gesture": null, "notes": "slumped"},
  "audio": {"transcript": "我今天有点累，陪我一下吧", "emotion": "sad", "emotion_conf": 0.7, "language": "zh"},
  "fused": {"emotion": "sad", "intent": "comfort_request", "urgency": "low", "confidence": 0.75}
}
```

### 期望决策要点（E04）

- `fallback=false`
- `action_group` 落在安抚类：`bow` / `wave`
- `action_prompt` 英文、温和、可生成
- 不输出踢打类 `*_shot*` / `wing_chun`

### 安全约束（决策提示词必须包含）

1. 用户愤怒/恐惧时，**禁止**攻击性 ActionGroup（kick/shot/punch）
2. `fused.confidence < 0.45` ⇒ `fallback=true`, `action_group=["stand"]`
3. `action_prompt` 必须是单人身体动作英文句，禁止抽象词（如 “be supportive”）
4. 一次最多 2–3 个 ActionGroup，避免超长序列拖延迟

---

## 4. 推荐测试顺序（仍不改大代码）

1. **人工填 20 条伪感知 JSON**，用现有小 LLM（如 qwen-turbo / gpt-4o-mini）只测决策 JSON 合法率  
2. 把产出的 `action_prompt` 批量喂给已有 `bench_pi_gen.py` / MoMask，测生成与关节有效性  
3. 同步把 `action_group` 在 TonyPi 上点名执行，确认即时反馈轨可用  
4. 统计四段耗时，对照第 2 节预算  
5. 通过后再接真实摄像头/麦克风小模型

---

## 5. 与现有源码的对应关系

| 本规范 | 现有可复用 |
|---|---|
| `action_group` | `embodied_intelligence/.../action.py` + `TonyPi/ActionGroupDict.py` |
| ASR / TTS / 云 LLM | `embodied_intelligence/common/config.py` |
| 相机帧队列 | `vllm_with_camera.py` 的 `image_queue` 思路 |
| 视觉小能力 | `TonyPi/Functions/FaceDetect.py`, `mediapipe_visual.py`, `gesture_control.py` |
| 关节输出 | MoMask `recover_from_ric` → `(T,22,3)`（已在 4GB 验证） |

注意：现有 LLM 规划是「函数名字符串 + eval」，联调阶段建议先**解析 JSON 白名单调用**，不要直接 `eval` 任意字符串。
